# NimbusCR – Proyecto #2 UNED 03102

Sitio estático demostrativo de una empresa ficticia de logística en Costa Rica.

## Contenido
- `index.html`: inicio, misión y visión.
- `servicios.html`: servicios de transporte.
- `rastreo.html`: seguimiento simulado (NCR-2026-001, 002, 003).
- `cotizacion.html`: formulario con validación HTML5; no envía datos.
- `css/estilos.css`: diseño adaptable.
- `js/principal.js`: menú, rastreo y formulario.
- `_headers`: propuesta de cabeceras de seguridad para Netlify (verificar en producción).

## Prueba local
Abre `index.html` en un navegador, o desde la carpeta ejecuta `python3 -m http.server 8000` y visita `http://localhost:8000`.
